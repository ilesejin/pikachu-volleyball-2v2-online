# Preserved computer artwork

This artwork is kept for a future use. It is not currently selectable or loaded by the game.

- `computer-source.png`: unmodified image-generation output.
- `computer.png`: prepared transparent 476 × 262 sheet with all 28 game poses.
- `computer.json`: per-frame head/neck accessory offsets for that body.
- `PROMPT.md`: original prompt and generation provenance.

The active new skin is Cyborg Pikachu under `src/resources/assets/images/skins/`. The computer source and prepared files are deliberately outside shipped assets.
